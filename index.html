3. Pixels & Resolution

A bitmap image is made from individually coloured pixels. Higher resolution means more pixels, normally improving detail but increasing the amount of image data and therefore file size.

5. Buffering & Streaming

Streaming lets media play while data is being transferred. Buffering temporarily stores some data ahead of playback to reduce interruptions.

6. Sound Sampling

Digital sound is created by taking measurements (samples) of an analogue sound wave. Increasing the sample rate takes more measurements each second, producing a closer representation but more data.

7. Compression

Compression reduces file storage requirements. Lossless allows the original to be fully restored; lossy permanently discards some data.
